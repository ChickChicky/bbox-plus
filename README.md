# Bbox Plus

A Bouygues Bbox integration with more than the official (deprecated) one.

* Loosely based on https://github.com/home-assistant/core/tree/58aaf6fa97ae57bb189b9d5e929864b74a1e3852/homeassistant/components/bbox

## Adding to HA
You have to manually add it to your [`configuration.yaml`](https://www.home-assistant.io/docs/configuration/)
```yaml
# ...
sensor:
  - platform: bboxplus
```
